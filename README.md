# Ava Sidebar - Extension Chrome Simple

Extension Chrome minimaliste avec sidebar pour chatter avec une IA via OpenRouter.

## Installation

1. Télécharge ce dépôt ou clone-le
2. Dans Chrome, va sur `chrome://extensions/`
3. Active le **Mode développeur** (en haut à droite)
4. Clique sur **"Charger l'extension non empaquetée"**
5. Sélectionne le dossier du projet

## Configuration

1. Clique sur l'icône de l'extension dans la barre d'outils
2. Le sidebar s'ouvre à droite
3. Clique sur **⚙️ Configurer API**
4. Entre ta clé API OpenRouter (commence par `sk-or-v1-`)
5. Choisis un modèle (recommandé: `anthropic/claude-3-haiku`)
6. Sauvegarde

## Utilisation

- Écris ton message dans la zone de texte
- Clique sur **Envoyer** ou appuie sur `Ctrl+Enter`
- La réponse s'affiche automatiquement

## Modèles recommandés

- `anthropic/claude-3-haiku` - Rapide et économique
- `anthropic/claude-3-sonnet` - Plus intelligent, un peu plus cher
- `google/gemini-flash-1.5` - Alternative gratuite avec crédits
